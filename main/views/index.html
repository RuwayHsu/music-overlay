新手教學指引：
  1. 點擊左側「點此快速取得 Token」，登入您要用來發言的 Twitch 帳號授權。
  2. 複製產生的 Token 貼入左側欄位，填寫實況頻道名稱並勾選「啟用」。
  3. 點擊「儲存設定並連線」，右上狀態顯示為綠燈即表示機器人已在聊天室就緒！
  4. 觀眾在聊天室輸入 >np 或 !np，即可即時收到目前歌曲與連結。
